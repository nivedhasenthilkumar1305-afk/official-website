# Tea Palette ☕🎨


Tea Palette is a personal artist portfolio website designed and developed using HTML, CSS, and JavaScript.

## Features
- Responsive design
- Interactive artwork gallery
- Smooth scrolling
- Dark mode
- Artistic UI animations

## Technologies Used
- HTML5
- CSS3
- JavaScript

## About
This project reflects my journey as a tea artist while exploring frontend web development and creative coding.
